# Sensitive reports

Report sensitive concerns privately, including a record that endangers someone or personal data that should be removed. Do not put these details in a public issue or pull request.

Use GitHub's private vulnerability reporting through **Security → Report a vulnerability**, if available, or email `intel[at]securityalliance[.]org`. This is the correction contact used on [lazarus.group/contact](https://lazarus.group/contact).

Include the affected record IDs or URLs, why the material is sensitive, and the correction or removal you suggest. Share only the details needed for review.
